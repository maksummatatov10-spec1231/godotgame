# 🔥 Dungeon Survivors

Пиксельный данжен-survivor на **Godot 4.3**. Выживи 10 минут!

![preview](docs/preview_mockup.png)

## 📁 Структура репозитория
| Папка | Что там |
|---|---|
| `game/` | **Проект Godot 4.3** (то, что входит в релизный zip) |
| `dist/` | Релизные zip-архивы по версиям |
| `docs/` | Превью и прочие материалы |
| `TUTORIAL_MAP.md` | **Инструкция: как нарисовать свою карту со стенами-коллизиями** |
| `ASSETS_REPORT.md` | Полный анализ ассет-паков |

> Исходные ассет-паки удалены из репозитория по требованию — игра использует
> уже нарезанные кадры в `game/assets/`.

## 📦 Релизы
См. раздел [Releases](https://github.com/maksummatatov10-spec1231/godotgame/releases).
В каждом релизе — прямая ссылка на чистый zip проекта из `dist/`.

## ▶️ Быстрый старт
Распакуй zip релиза → Godot 4.3 → Import → `project.godot` → **F5**.
Управление: WASD/стрелки, 1/2/3 — выбор улучшений, R — рестарт.
